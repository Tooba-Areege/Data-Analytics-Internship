## 🎯 Objective

The objective of this task is to compare categories in the cleaned Titanic dataset and identify meaningful patterns using Pandas.

### Analytical Question

**How does the survival rate differ between male and female passengers?**

---

## 📊 Analysis Performed

The dataset was grouped by the **Sex** column. For each gender, the following statistics were calculated:

- Total number of passengers
- Survival rate (percentage)

The results were summarized in a comparison table.

---

## 🔍 Findings

The comparison shows that survival rates differ between male and female passengers. This suggests that gender was an important factor influencing survival on the Titanic.
