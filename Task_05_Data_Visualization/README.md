## 🎯 Objective

The objective of this task is to visualize key patterns in the cleaned Titanic dataset using basic charts. Data visualization helps present information clearly, making trends and comparisons easier to understand.

---

## 📈 Charts Created

### 1. Survival Count (Bar Chart)

**Takeaway:** Most passengers in the dataset did not survive.

### 2. Average Age by Passenger Class (Line Chart)

**Takeaway:** The average age varies across passenger classes.

### 3. Gender Distribution (Pie Chart)

**Takeaway:** The dataset contains a higher proportion of male passengers than female passengers.

### 4. Passenger Class Distribution (Bar Chart)

**Takeaway:** Most passengers belonged to the third passenger class.
