## 🎯 Objective

The objective of this task is to build a simple dashboard that summarizes key insights from the cleaned Titanic dataset. The dashboard combines key performance metrics with basic visualizations to provide a quick overview of the data.

### Dashboard Question

**How can the most important information from the Titanic dataset be presented in a single dashboard?**

---

## 📊 Dashboard Components

The dashboard includes:

- Total Passengers
- Survival Rate
- Average Age
- Average Fare
- Survival Count Bar Chart
- Passenger Class Distribution Bar Chart

---

## 🔍 Key Insights

- The dashboard provides a quick summary of the dataset using four important metrics.
- The charts help compare passenger survival and class distribution.
- Combining metrics and visualizations makes it easier to understand the dataset at a glance.
