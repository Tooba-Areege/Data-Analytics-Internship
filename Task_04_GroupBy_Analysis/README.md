## 🎯 Objective

The objective of this task is to perform a GroupBy analysis using Pandas and answer a specific question about the Titanic dataset.

### Analytical Question

**How does passenger class affect the average fare, average age, and survival rate?**

---

## 📊 Analysis Performed

The cleaned Titanic dataset was grouped by the `Pclass` column.

For each passenger class, the following values were calculated:

- Total number of passengers
- Average age
- Average fare
- Survival rate

The survival rate was converted into a percentage to make the results easier to understand.

---

## 🔍 Key Insight

The GroupBy analysis allows passenger classes to be compared based on their average fare, age, and survival rate. This helps identify differences between passenger groups and demonstrates how grouping data can reveal meaningful patterns and insights.
