## 🎯 Objective

The objective of this task is to create advanced visualizations using the cleaned Titanic dataset to uncover deeper insights. A stacked bar chart and a correlation heatmap were created to analyze survival patterns and relationships between numerical features.

### Analytical Question

**How do passenger class and numerical features reveal deeper patterns in the Titanic dataset?**

---

## 📊 Analysis Performed

Two advanced visualizations were created:

- **Stacked Bar Chart:** Compared passenger survival across different passenger classes.
- **Correlation Heatmap:** Displayed the relationships between numerical features such as Age, Fare, SibSp, and Parch.

---

## 🔍 Key Insight

The stacked bar chart shows that survival rates vary across passenger classes, while the heatmap highlights the strength of relationships between numerical variables. These visualizations help reveal patterns that are not immediately visible in raw data.
